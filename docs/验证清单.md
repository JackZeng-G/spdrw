# 真机验证清单

在真实硬件上部署前逐项确认。所有"读取"类操作无风险;"写入/保护"类操作请先读懂每一步。

## 0. 环境

- [ ] Windows 10/11 x64, 已安装 [PawnIO](https://pawnio.eu/) 最新版
- [ ] 以管理员身份运行 `SPDReaderWriter.exe`
- [ ] 主界面右上角显示 "就绪 · N 个控制器", 无黄色警告条
- [ ] (可选) BIOS 中 "SPD Write Disable" 关闭(写入前必须)

## 1. 控制器枚举(只读)

- [ ] Intel 平台: 出现 "Intel PCH SMBus (I801)" 且显示 PCI 地址
- [ ] AMD 平台: 出现 KernCZ PIIX4 (可能 2 个端口条目)
- [ ] 服务器 Skylake-SP: 出现 "Skylake IMC SMBus" ×2
- [ ] 与 CPU-Z / HWiNFO 的 SMBus 控制器 PCI ID 一致

## 2. 扫描与读取(只读)

- [ ] 每根内存条出现在 0x50-0x57, 数量与插槽数一致
- [ ] 类型识别正确(DDR4 显示 DDR4, DDR5 显示 DDR5)
- [ ] "读取" 得到 512B(DDR4)/1024B(DDR5), 十六进制视图按高 nibble 着色
- [ ] 信息面板: 厂商/部件号/序列号/生产日期与 CPU-Z、Thaiphoon 一致
- [ ] 容量与实际一致(例: 2×16GB 双列显示 16 GiB)
- [ ] DDR4: CRC 校验通过(若失败, dump 可能分页错位 — 重读一次)
- [ ] DDR4 时序: tCL/tAA/tRCD/tRP/tRAS 与 BIOS/CPU-Z 一致
- [ ] XMP 条目: 频率-时序-电压与包装标签一致
- [ ] DDR5: CRC(基础段)通过; XMP/EXPO 存在性正确
- [ ] (对照) DDR2/DDR3 老平台: 容量与部件号正确

## 3. 写保护状态(只读)

- [ ] "查询保护状态" 返回块列表: 出厂未保护显示全 🔓
- [ ] 对已 RSWP 的条(可先用别条测试): 对应块显示 🔒
- [ ] DDR5: MR12/MR13 位图与 Thaiphoon 一致
- [ ] 已 PSWP 的条: 显示 "PSWP 永久保护已生效"

## 4. 写入(有风险 — 先备份!)

- [ ] 已保存原始 dump 并**另存一份**冗余备份
- [ ] 修改 1 个自定义字段(如部件号尾部)后写入 → 增量模式日志显示 "写入完成"
- [ ] 自动回读校验通过; 重新读取内容与目标一致
- [ ] 对启用 RSWP 的条写入 → 被拒绝且无部分写入
- [ ] CRC 变更后(如改了 base 区) → 用界面修复功能或原版工具重算后再写

## 5. RSWP(有风险 — 不可逆性因条而异)

- [ ] 先在**可牺牲**的条上测试; 部分颗粒 RSWP 清除需要 DDR5 离线模式或断电
- [ ] RSWP 设置单块 → 状态显示该块 🔒; 重上电后仍保护
- [ ] RSWP 清除 → 全部 🔓 (DDR4 SWP 清除 quick 命令; DDR5 走 MR12/MR13=0 + 离线模式)

## 6. 异常路径

- [ ] 未装 PawnIO(或卸载后): 黄条提示下载链接, 不崩溃
- [ ] 非管理员运行: 黄条提示需管理员
- [ ] 拔掉内存条后读取: 报 NACK 错误并记录日志, 不崩溃
- [ ] 写入超过 SPD 大小的文件: 拒绝

## 已知边界

- PSWP(永久写保护)**无法通过本工具设置** — 需要高压(HV)编程器; 显示状态仅供识别
- DDR5 时序(如 tAA/tRCD)不解析 —— 与原版范围一致
- 笔记本/紧凑机型 SPD 可能挂在笔记本专用控制器上, 不在三种支持之列
- 部分 AM5/ITX 板 SMBus 由Slug 芯片桥接, PIIX4 端口可能需要两个都试
