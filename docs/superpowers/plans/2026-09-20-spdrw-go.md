# SPD-RW Go Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Go + Wails 复刻 SPD-Reader-Writer 为 Windows 桌面应用 spdrw.exe：经 PawnIO 签名模块直读直写 SMBus，含扫描/dump/写入/校验/RSWP·PSWP，SPD 解析 DDR4/DDR5 详尽 + DDR2/3 基本信息。

**Architecture:** 四层——`smbus.Transport` 接口（PawnIO 后端 + Fake 测试实现）、`eeprom`（SPD EEPROM 协议：分页/RSWP/PSWP）、`spd`（纯函数解析）、`app`+`frontend`（Wails v2 服务层与原生 HTML/JS UI）。

**Tech Stack:** Go 1.27、Wails v2（go:embed 资产、无 CGO、无 node 构建链）、PawnIO（SmbusI801/SmbusPIIX4/SmbusIntelSkylakeIMC 签名模块）、golang.org/x/sys/windows。

**Spec:** `docs/superpowers/specs/2026-09-20-spdrw-go-design.md`

## Global Constraints

- 全部 Go 代码 `gofmt` 通过、`go vet ./...` 干净、`go test ./...` 全绿（Linux）。
- Windows 专属代码必须带 `//go:build windows`；纯逻辑（封送、状态映射、解析、协议层）不得依赖 Windows，保证容器内可测。
- PawnIO 模块 .bin 固定版本，不修改其二进制；只随 exe 内嵌释放。
- 用户可见文案中文；错误一律经 `errors` 包装带上下文。
- 危险操作（写入、WP、PSWP）在服务层有确认参数，UI 层有确认交互，双层防护。
