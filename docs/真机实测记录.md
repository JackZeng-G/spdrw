## 2026-09-21 · V1 读取 + 写保护状态 + 编辑器

| 项 | 结论 | 原始证据 |
|---|---|---|
| 设备枚举 | 2 根 SPD(0x50 起) | `发现 2 个 SPD 设备, 请在列表中选择要读取的 DIMM` |
| 类型/容量识别 | DDR5 / 1024 字节 | `已选择 0x50 (DDR5, 1024 字节)` |
| 写保护状态查询 | 正常(修复前返回 null) | 界面显示块范围与锁定状态 |
| **读速(字读档)** | **1024B: 事务 512 次 / 16.509s** | `[16:05:33] 读取 1024 字节: 字读(2 字节/事务); 事务 512 次, 耗时 16.509s(等待 2 ms)` |
| 编辑器改字段 | 正常(hex 按十六进制解析) | `原始编辑: 0x203 = 0x24` / `0x203 = 0x5A` |

### 读速对照(同一根条)

| 档位 | 每事务 | 事务数 | 实测耗时 |
|---|---|---|---|
| 块读(协议 5, 32B) | 32B | 33 | — **被 NACK, 本机不可用** |
| 字读(协议 3, 2B) | 2B | 512 | **16.509s**(实测) |
| 逐字节(协议 2, 1B) | 1B | 1024 | 32.145s(实测, 上一版) |

换算: 单次事务 ≈ 32ms, 与字节数无关 → **提速只能靠减少事务数**。
512 次事务已接近"2 字节协议"的物理上限;再快要等平台/驱动支持块读(I801 路径实现了块读, 本机走 PIIX4 无解)。
